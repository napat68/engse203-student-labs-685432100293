## ครั้งที่ 2

**ถามอะไร**

> หลังรัน `npm run check` ได้ 25/28 รายการ ช่วยวิเคราะห์ว่าทำไมการตรวจ details สั้นกว่า 10 ตัวอักษร, priority ไม่ถูกต้อง และรายละเอียด error จึงไม่ผ่าน

**AI ตอบว่าอย่างไร (สรุปสั้น)**

> AI วิเคราะห์ว่าปัญหาอยู่ที่ `validateRequest.js` ซึ่งตรวจเพียงว่าข้อมูลมีครบหรือไม่ แต่ยังไม่ได้ตรวจความยาวของ details, ค่าที่อนุญาตของ priority และไม่ได้ส่งรายละเอียดของ validation error

### ถ้ามีครั้งที่ 3 ในไฟล์

ถ้า Template มีพื้นที่ต่อ ผมว่าใส่อีกครั้งจะสมจริงกว่า เพราะเราใช้ AI หลายช่วง:

**ถามอะไร**

> ช่วยตรวจสอบผลการทดสอบ API และอธิบายความหมายของ HTTP Status Code 200, 201, 204, 400 และ 404 ที่ใช้ใน LAB06

**AI ตอบว่าอย่างไร (สรุปสั้น)**

> AI อธิบายว่า 200 คือสำเร็จ, 201 คือสร้างข้อมูลสำเร็จ, 204 คือลบสำเร็จโดยไม่มี response body, 400 คือข้อมูลที่ส่งมาไม่ถูกต้อง และ 404 คือไม่พบ resource หรือ route

**ใช้ส่วนไหน / แก้เองตรงไหน**

> ใช้เป็นแนวทางตรวจผลใน Postman โดยทดสอบ request จริงกับ API และเปรียบเทียบ Status Code กับผลลัพธ์ที่โจทย์กำหนด
