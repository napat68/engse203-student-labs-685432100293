# หลักฐานการสาธิตระบบ — ENGSE203 LAB 11 (A4)

## ช่วง A — สาธิตการทำงานของระบบ (ประมาณ 3–4 นาที)

**ลิงก์วิดีโอ:** รอบันทึกวิดีโอ

รายการที่ต้องสาธิต:
- [ ] เปิดระบบ React + Express API + SQLite
- [ ] แสดงรายการคำร้องทั้งหมด
- [ ] เพิ่มคำร้องใหม่
- [ ] เปลี่ยนสถานะคำร้อง
- [ ] ลบคำร้อง
- [ ] เปิด `/api/health` เพื่อตรวจสอบสถานะระบบ
- [ ] ปิดและเปิดเซิร์ฟเวอร์ใหม่เพื่อพิสูจน์ว่าข้อมูลยังอยู่
- [ ] เปิดระบบ Production ผ่านพอร์ตเดียว

## ช่วง B — อธิบาย Source Code (ประมาณ 4–5 นาที)

**ลิงก์วิดีโอ:** รอ บันทึกวิดีโอ

รายการที่ต้องอธิบาย:
- [ ] Frontend เรียก API ผ่าน `frontend/src/services/`
- [ ] การไหลของข้อมูลผ่าน Route → Controller → Service
- [ ] การอ่านและเขียนข้อมูล SQLite ใน `requestService.js`
- [ ] การอ่าน Environment Variables ใน `config.js`
- [ ] การตรวจสอบสถานะระบบผ่าน `healthRoutes.js`
- [ ] ความแตกต่างระหว่าง Development และ Production
