## เครื่องมือ AI ที่ใช้

- ChatGPT

## วัตถุประสงค์ในการใช้

ใช้ AI เป็นผู้ช่วยในการเรียนรู้และตรวจสอบการทำ LAB09 เรื่อง Relational Database และ SQL โดยใช้เพื่อช่วยอธิบายแนวคิด ตรวจสอบโครงสร้าง SQL และวิเคราะห์ข้อผิดพลาดที่เกิดขึ้นระหว่างการทดลอง

## ตัวอย่างการใช้งาน

1. ใช้ช่วยตรวจสอบการออกแบบตาราง `users` และ `requests` รวมถึง Primary Key และ Foreign Key
2. ใช้ช่วยตรวจสอบคำสั่ง SQL ใน `schema.sql` และ `queries.sql`
3. ใช้ช่วยอธิบายความสัมพันธ์แบบ One-to-Many ระหว่าง `users` และ `requests`
4. ใช้ช่วยวิเคราะห์และทดสอบ Constraint ได้แก่ FOREIGN KEY, CHECK, UNIQUE และ NOT NULL
5. ใช้ช่วยอธิบายการใช้ JOIN เพื่อรวมข้อมูลคำร้องกับชื่อผู้แจ้ง
6. ใช้ช่วยตรวจสอบข้อผิดพลาดระหว่างการทดสอบ และเสนอแนวทางแก้ไข
